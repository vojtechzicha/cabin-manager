# Cabin Manager

Cabin Manager (codename **Chata**) is a group-trip organizing app — plan the
dates, claim a bed, split the money, and keep everyone in the loop. The same app
re-skins itself for every trip from a background photo and an accent colour.

Early-stage prototype.
